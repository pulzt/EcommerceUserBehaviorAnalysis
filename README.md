电商用户行为与用户价值分析

项目简介
本项目基于电商用户行为数据，使用 MySQL 进行数据处理与分析，并通过 Power BI 进行数据可视化，分析用户行为特征、商品品类表现、购买路径及用户价值，为电商运营提供数据参考。

使用工具
MySQL
Power BI

数据说明
数据包含用户浏览（PV）、收藏（FAV）、加购（CART）和购买（BUY）等行为记录。
主要字段：
user_id：用户ID
item_id：商品ID
category_id：商品品类ID
behavior_type：行为类型
timestamps：行为时间戳

分析内容
用户行为分析：统计不同用户行为的数量及时间趋势。
商品品类分析：分析不同品类的用户行为分布。
购买路径分析：对比直接购买、收藏后购买、加购后购买三种路径的转化情况。
RF用户分层：根据最近购买时间（R）和购买频次（F）对用户进行分层。

项目文件
sql/：SQL分析代码
powerbi/：Power BI文件及可视化截图
数据口径说明
购买频次以购买行为记录次数近似，不代表真实订单数。
用户分层采用RF简化模型，未包含消费金额（M）
